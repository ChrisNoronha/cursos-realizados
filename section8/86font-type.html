Demonstração da Unidade CH

A unidade CH é baseada na largura do caractere "0" da fonte atual.

É especialmente útil para:

  • Definir larguras de texto legíveis
  • Criar layouts consistentes com fontes monoespaçadas
  • Controlar comprimentos de linha para melhor legibilidade

Parágrafo com 60ch

Este parágrafo tem uma largura de 60 caracteres, que é considerada uma largura ideal para leitura. O texto fica confortável para ler e não cansa os olhos do leitor.

Este é um parágrafo mais estreito, com 45 caracteres de largura. Bom para textos em dispositivos menores.
